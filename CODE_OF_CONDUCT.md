# Community conduct

We want a welcoming environment for learners and maintainers at all experience levels.

Be considerate, discuss code and ideas respectfully, provide actionable feedback, and avoid harassment, discrimination, personal attacks or sharing others' private information. Maintainers may edit or remove abusive contributions and restrict participation if necessary.

For sensitive conduct reports, contact the Scarp project maintainers through their published organization contact channel rather than opening a public issue with private details. Technical bug reports belong in GitHub Issues.
