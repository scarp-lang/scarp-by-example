## Reproduce real compiler behavior

Build the actual tagged Scarp source, or use its verified binary archive after checking SHA-256 sums.

```sh
git clone https://github.com/scarp-lang/scarp.git
cd scarp
git checkout 2eeed0aa52ccb59523307841ad8ffbd83f8911a8
cargo build --locked --offline
./target/debug/scarp version
```

From the course root, with that executable on PATH:

```sh
scarp verify examples/01-basics/01-hello.srp
scarp exec examples/01-basics/01-hello.srp
scarp verify tutorials/module-inspection
scarp inspect modules --json tutorials/module-inspection
scarp inspect modules --json tutorials/module-inspection/src/main.srp
scarp launch tutorials/module-inspection
```

Only `launch` here runs the project; its output is exactly `42` followed by LF. `inspect modules` is **read-only static inspection**, not program execution and not generated program stdout. The module JSON is versioned metadata, so no fake stdout fixture is claimed. See [English explanation](../project-inspection.md), [हिन्दी मार्गदर्शिका](../hi/project-inspection.md) and [compiler compatibility](../compatibility.md).

The automated verification commands are:

```sh
python scripts/verify_examples.py --compiler /path/to/scarp
python scripts/verify_guided_labs.py --compiler /path/to/scarp
python scripts/verify_cli.py --compiler /path/to/scarp
```

The GitHub Pages build runs them against pinned source; all 50 numbered lessons and six lab solutions must match their exact recorded outputs.

## Limitations, license and delivery

Scarp alpha.5 remains an **experimental prerelease**. Its scalar C11 source emitter is a restricted **Rust embedding API**, not a public `scarp compile` command, native language compiler or stable ABI. The interpreter's support for functions, numerical vectors, matrices and multi-argument output must not be mistaken for C emitter support. There is no native Scarp application installer bundled in this course; GitHub generates ZIP and tar.gz source archives automatically.

The website does not run Scarp in the browser, infer quiz correctness beyond voluntary local multiple-choice feedback, or automatically judge user-written programs. No accounts or source uploads are needed. Original course content, website and tests use MIT licensing; compiler-derived source, support modules and exact fixtures are attributed as required by [third-party notices](../../THIRD_PARTY_NOTICES.md) and their Apache-2.0 terms. Historical releases `v0.1.0-alpha.1`, `v0.1.0-alpha.2` and `v0.1.0-alpha.3` remain immutable snapshots of their respective compiler targets.
