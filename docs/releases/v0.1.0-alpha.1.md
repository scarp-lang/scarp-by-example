# Scarp by Example v0.1.0-alpha.1

**First course prerelease: 50 runnable lessons across six chapters, with English and Hindi explanations.**

This is a **Scarp by Example course prerelease**, not a Scarp compiler release or a guarantee of stable language syntax. Every runnable example targets the **published Scarp compiler v0.0.5-alpha.3**, exact source commit `7715c28df09c7703b39e14fddb963275b25df476`.

## Included
- Fifty numbered `.srp` lessons and fifty byte-exact `.stdout` fixtures, from basics through numerical collections, modules and AI-oriented mathematics.
- English and Hindi teaching material for all six chapters, with a [searchable catalog](https://scarp-lang.github.io/scarp-by-example/).
- Bilingual quickstarts for the real Scarp CLI, including static `verify`, interpreter `exec`, source `inspect` and legacy `check`.
- Module exercises for typed integer-series imports, public/private APIs, and exported signatures.
- Linux, Windows and macOS validation against an immutable compiler commit, plus CLI, translation and import-graph tests.

## Run the lessons

Build the exact Scarp compiler source commit above, then follow the [README](https://github.com/scarp-lang/scarp-by-example#start-here) and [compatibility policy](https://github.com/scarp-lang/scarp-by-example/blob/main/docs/compatibility.md). From the course root, use `scarp verify PATH_TO_LESSON.srp` to statically check a lesson, then `scarp exec PATH_TO_LESSON.srp` to run it. Compare the resulting bytes with the adjacent `.stdout` file.

## Limits and licenses

Scarp is experimental; these examples do **not** promise production model training, automatic differentiation, native code emission, GPUs, general lists/maps/sets, async/networking or agent APIs.

Original teaching text and tooling use **MIT**; upstream compiler-derived source and expected-output fixtures retain **Apache-2.0** licensing. See [provenance](https://github.com/scarp-lang/scarp-by-example/blob/main/THIRD_PARTY_NOTICES.md) and both license files.

GitHub source archives include code, examples, fixtures, documentation, and licenses. **No Scarp compiler binary or installer is bundled.**
