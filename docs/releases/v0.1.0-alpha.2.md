# Scarp by Example v0.1.0-alpha.2

**Verified course prerelease: 50 runnable Scarp lessons, six chapters, a new real project workflow tutorial, English and Hindi, and a local-first learning portal.**

This is a **Scarp by Example course prerelease**, **not a Scarp compiler release** and not a stable language guarantee. The lesson corpus now targets the **published official Scarp compiler v0.0.5-alpha.4**, annotated tag resolving to immutable source commit `79141329176f5dce51457e90a6652902f6432135`.

## Changes since the first course prerelease

- The same 50 numbered `.srp` examples and byte-exact `.stdout` fixtures, newly reverified against the released alpha.4 compiler across **Linux, Windows and macOS**.
- **New project workflow:** Learn real `scarp create DIRECTORY`, static `scarp verify DIRECTORY` and interpreter-backed `scarp launch DIRECTORY`. A checked-in `Scarp.project`, source program and expected-output fixture can be run locally. The tutorial is separate from the 50 numbered lessons.
- **Full bilingual project guide** in English and Hindi, and updated CLI quickstarts that distinguish static file checks, static project checks and runtime execution.
- The searchable [Scarp by Example website](https://scarp-lang.github.io/scarp-by-example/) now has **58 static HTML pages**: a homepage, six chapter pages, fifty lesson pages and a new [projects tutorial](https://scarp-lang.github.io/scarp-by-example/projects/).
- Each lesson page offers in-page English/Hindi explanations, a source-backed Hindi practice question, real code, exact output, previous/next navigation and deep links.
- Optional browser-local completion tracking and resume. Lesson IDs are saved **only in localStorage**, without accounts or analytics; learners can clear their progress.
- The automated compiler/CLI validation now exercises alpha.4 project creation, manifest integrity, static verification, interpreter launch, rejection of existing destinations, runtime-only errors, invalid manifest paths and schema-versioned JSON diagnostics.

## Reproduce the course

Obtain the [published Scarp v0.0.5-alpha.4 compiler](https://github.com/scarp-lang/scarp/releases/tag/v0.0.5-alpha.4), or build its exact source commit `79141329176f5dce51457e90a6652902f6432135`. From the Scarp by Example repository root:

```sh
scarp verify examples/01-basics/01-hello.srp
scarp exec examples/01-basics/01-hello.srp
scarp verify tutorials/first-project
scarp launch tutorials/first-project
```

`verify` is static-only; `exec` and `launch` invoke the real interpreter. Source filenames and relative project paths are resolved from the course root. The [compiler compatibility policy](https://github.com/scarp-lang/scarp-by-example/blob/main/docs/compatibility.md), [English project tutorial](https://github.com/scarp-lang/scarp-by-example/blob/main/docs/project-workflow.md) and [Hindi project tutorial](https://github.com/scarp-lang/scarp-by-example/blob/main/docs/hi/project-workflow.md) include the complete instructions.

## Prerelease limitations and licensing

Scarp remains an experimental language. `create`/`launch` do **not** provide native source-to-executable compilation, a package manager, dependency locks or stable workspace semantics. The verified lessons do not imply a general GPU backend, tensor/autograd framework, general lists/maps/sets, language async/networking or autonomous agents.

Original course material, site and tests are **MIT**; compiler-derived examples, companion modules and exact stdout fixtures retain the upstream **Apache-2.0** licensing as recorded in the project's [third-party notices](https://github.com/scarp-lang/scarp-by-example/blob/main/THIRD_PARTY_NOTICES.md).

GitHub's automatically generated source archives contain the entire course and project tutorial. **No Scarp compiler binary or installer is bundled**. The previous course prerelease, v0.1.0-alpha.1, remains available unchanged as its earlier alpha.3-targeted snapshot.
