# Scarp by Example v0.1.0-alpha.5 — Verified lessons and compiler alpha.2

This is an experimental, open-source **course prerelease**, **not a Scarp compiler release** and not a stable language or API compatibility guarantee.

The course is tested against the publicly published [Scarp v0.0.6-alpha.2](https://github.com/scarp-lang/scarp/releases/tag/v0.0.6-alpha.2), with immutable annotated-tag source commit `398b8ff705154a02423fe458ce3a427401e81e31`. It does **not** use the moving compiler `main` branch. The release workflow requires both the Linux/macOS/Windows example-verification workflow and the independent Pages/catalog workflow to have succeeded on the **exact same main-branch commit** before this prerelease can be published.

## What's new since v0.1.0-alpha.4

- **52 lessons across six chapters**, with original Scarp `.srp` programs and exact UTF-8 `.stdout` fixtures. The newly added fourth control-flow lesson demonstrates nested `repeat` loops, inner `continue`, counters and an accumulator with verified output `9 3 24`.
- **Compiler compatibility upgraded to the published Scarp v0.0.6-alpha.2**. All 52 runnable lessons must pass both silent static `scarp verify` and byte-exact interpreter `scarp exec` checks on Ubuntu, macOS and Windows. The six guided lab starters and reference solutions, project inspection, CLI and source-navigation checks use the same immutable compiler source.
- **69 HTML pages** generated by the dependency-free, static lesson-site builder, including standalone pages for every verified example, six chapter overviews, project tutorials, and the coding lab directory.
- **18 checkpoints**, three per chapter, have bilingual English/Hindi source-backed questions with explanations. Chapter overviews now provide an expandable three-question review using those same questions rather than inventing untested new answers.
- **Six coding labs** (one per chapter) retain independently verified starter and solution programs with fixed expected output; learners run and compare programs using the local Scarp compiler.
- **Practical learning navigation** includes previous/next chapter links, last-lesson handoffs to verified labs, searchable original source previews and shareable filtered search results.
- **Optional output prediction exercises** offer private, line-aware feedback about differing output, whitespace and capitalization, with explicit reveal and retry. This checks displayed fixture text only; it never executes Scarp in a web browser or saves predictions.
- **Read-only source navigation workshop**, with bilingual explanations and an interactive view of validated declaration/reference links across two real module files. The map is pinned to the exact compiler commit; it is not a language server or rename tool.
- **Optional local-only lesson progress** remains separate from quiz scores and program execution. Browser storage is optional; there are no accounts, source-code uploads or hosted judging services.

## Important compiler distinctions

Compiler alpha.2 introduces opt-in caching, graph invalidation planning and eviction APIs **for Rust embedders**, with internal compiler safety improvements. These are not new Scarp-language statements, CLI commands, native compilation, a file watcher or a browser runtime. Existing experimental C11 emission is a limited Rust embedding API; there is **no** public `scarp compile` command, general native executable generator, GPU execution, async runtime or full model training framework in this prerelease.

The code in this course must not be described as stable Scarp syntax. Unreleased feature proposals remain separate from runnable lessons.

## Verify locally

From a checked-out Scarp compiler repository:

```sh
git checkout 398b8ff705154a02423fe458ce3a427401e81e31
cargo build --locked --offline
./target/debug/scarp version
```

On Windows, use `target\\debug\\scarp.exe`. From a checkout of **Scarp by Example**, with that compiler executable available:

```sh
python scripts/verify_examples.py --compiler /path/to/scarp
python scripts/verify_guided_labs.py --compiler /path/to/scarp
python scripts/verify_cli.py --compiler /path/to/scarp
python -m unittest discover -s scripts -p 'test_*.py'
python scripts/build_site.py --output dist
```

For the new lesson, run:

```sh
scarp verify examples/02-control-flow/04-nested-repeat.srp
scarp exec examples/02-control-flow/04-nested-repeat.srp
```

Expected stdout is exactly `9 3 24` followed by a newline. The reference source and fixture are checked into the repository; do not alter the fixture to mask a mismatch.

## Release scope

The prerelease contains the course's source files and learning resources in the automatically generated GitHub source archives. It does not bundle a standalone compiled Scarp CLI or provide installable native applications. Obtain platform-specific binaries from the separately verified [Scarp compiler release](https://github.com/scarp-lang/scarp/releases/tag/v0.0.6-alpha.2), checking its published SHA-256 sidecars.
