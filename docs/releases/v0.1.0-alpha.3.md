# Scarp by Example v0.1.0-alpha.3

**Source-verified learning-path course prerelease** — 50 numbered runnable lessons, 18 bilingual comprehension checkpoints, six compiler-tested coding labs and connected Read → Check → Build pathways across all six chapters.

This is a **Scarp by Example course prerelease**, **not a Scarp compiler release** or a promise of stable language syntax. It targets the published official Scarp compiler **v0.0.5-alpha.4**, pinned to immutable commit `79141329176f5dce51457e90a6652902f6432135`. The compiler pin, original numbered Scarp sources and byte-exact stdout fixtures remain unchanged from the previous course prerelease.

## New since v0.1.0-alpha.2

- **18 English/Hindi checkpoint questions**, three in each chapter, verified at build time against an exact line of the corresponding lesson's checked-in compiler stdout. Each question includes three choices and a source-backed bilingual explanation. Correctness feedback is immediate, but scores are not recorded.
- **Six practical coding labs**, one per chapter, with bilingual challenge instructions, an editable local `starter.srp`, a reference `solution.srp`, byte-exact `solution.stdout`, hints and explanations. CI runs the real pinned Scarp compiler against both: starters compile but intentionally do not already produce the goal; solutions match fixtures byte for byte on Linux, macOS and Windows.
- **Read → Check → Build chapter pathways** connecting every chapter's lessons to its three checkpoints and its guided coding lab. Learners can navigate between chapter, lesson, checkpoint and lab pages without inventing automatic assessment.
- **Private local completion backups**: export and import JSON files of explicitly completed lesson IDs without accounts, network uploads or analytics. Imports validate their contents and merge without clearing existing progress.
- **Mobile navigation and accessibility**: keyboard- and touch-operable native Menu disclosure replaces the horizontally scrolling mobile header. Escape closes it and returns focus to its trigger; link destinations match desktop navigation. The menu and content navigation work without JavaScript.
- **65 source-generated HTML pages**: home, six chapter overviews, fifty lesson pages, project workflow, six individual coding lab pages and a lab index. All site pages preserve real code, accurate output, and links to original sources.

## Reproduce the verified learning materials

Use the [published Scarp compiler v0.0.5-alpha.4](https://github.com/scarp-lang/scarp/releases/tag/v0.0.5-alpha.4), or build its exact source commit `79141329176f5dce51457e90a6652902f6432135`. From this repository's root, use the `scarp` CLI from that compiler:

```sh
scarp verify examples/01-basics/01-hello.srp
scarp exec examples/01-basics/01-hello.srp
scarp verify labs/01-basics/starter.srp
scarp exec labs/01-basics/starter.srp
scarp verify labs/01-basics/solution.srp
scarp exec labs/01-basics/solution.srp
```

The first lab's reference solution must print exactly `42`; the starter deliberately prints another result. Copy the starter to `attempt.srp` **within the same lab folder** before editing, particularly for labs that import their own `_support` modules. The [guided lab instructions](https://github.com/scarp-lang/scarp-by-example/blob/main/docs/guided-labs.md) explain how to compare output locally.

For complete CI reproduction with a built compiler:

```sh
python scripts/verify_examples.py --compiler /path/to/scarp
python scripts/verify_guided_labs.py --compiler /path/to/scarp
python scripts/verify_cli.py --compiler /path/to/scarp
```

The static [learning website](https://scarp-lang.github.io/scarp-by-example/) **does not execute Scarp in the browser**. Practical attempts are run locally with the actual compiler. Quiz scores and successful lab runs are not persisted or inferred; optional lesson completion remains a separate, user-controlled browser preference.

## Scope and limitations

Scarp remains prerelease software. The numeric/AI examples demonstrate published low-level operations, not a general training framework, GPU stack or agent runtime. General collection types, structured errors, async/networking, native compilation and package tooling are not taught as implemented. The course's **50 numbered runnable lesson sources** are not inflated by the six separate guided labs or by quiz questions.

The course's original site, teaching material and tests are MIT; compiler-derived examples, upstream support modules and output fixtures retain their attributed Apache-2.0 terms as recorded in [THIRD_PARTY_NOTICES.md](https://github.com/scarp-lang/scarp-by-example/blob/main/THIRD_PARTY_NOTICES.md). GitHub generates source archives automatically; **no compiler binary or installer is included**. Earlier prereleases remain available as historical snapshots.
