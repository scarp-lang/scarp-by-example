# Minimal static catalog

The site is generated by `python scripts/build_site.py` from the real numbered `.srp` lessons, their exact `.stdout` fixtures and the chapter guides. `dist/` is deliberately ignored by Git.

Search is progressive enhancement; the complete course works without JavaScript. Code is shown for reading; the site does **not** execute Scarp in a browser.

The Pages workflow performs compiler verification before publishing and requires the repository's **Settings → Pages → Build and deployment → GitHub Actions** setting. Do not advertise the Pages URL until a real deployment succeeds.
