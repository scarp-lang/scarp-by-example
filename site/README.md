# Minimal static catalog

The site is generated by `python scripts/build_site.py` from the real numbered `.srp` lessons, their exact `.stdout` fixtures and the chapter guides. `dist/` is deliberately ignored by Git.

Search is progressive enhancement; the complete course works without JavaScript. Code is shown for reading; the site does **not** execute Scarp in a browser.

The Pages workflow performs compiler verification before publishing and requires the repository's **Settings → Pages → Build and deployment → GitHub Actions** setting. The first publishing workflow [completed successfully on November 2, 2026](https://github.com/scarp-lang/scarp-by-example/actions/runs/41405985206) and reported the URL [scarp-lang.github.io/scarp-by-example](https://scarp-lang.github.io/scarp-by-example/). Future deployments remain gated by compiling and verifying every example. The catalog does not claim browser-side code execution.


All six chapters have English source guides and corresponding [Hindi companion guides](../docs/hi/README.md). The static builder requires a Hindi chapter file before generating each section, and the CI translation-parity tests check every original `.srp` and `.stdout` link. The site links to source documents on GitHub; it does not run code or translate Scarp syntax.
